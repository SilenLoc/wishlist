# How to Use This Wishlist

This wishlist is designed to be a living document that should help others find
gifts for me.

## Navigation

Use the sidebar to navigate between different categories and individual items.
Each category contains items that are related in purpose or use case.

## Items

Each item page shows the price, where to buy it, and a short description.
Where possible, links point to the official store, or to Galaxus.ch for the
Swiss market.

## Adding items

Items live in this repository as Markdown files, one file per item, grouped in
category folders. Pushing to the `main` branch rebuilds and redeploys the
site automatically.
